# 项目概述

Sniffing Browser（`sniffing_browser`）：跨端媒体嗅探下载器。内置 WebView 打开网页，
捕获页面加载的图片、音频、视频与 HLS / DASH 分片，提供下载、合并、转码与导出。
自用工具，不上架。

目标平台：Android、HarmonyOS NEXT、Windows，一套 Flutter / Dart 代码。

## 当前状态

- Windows 端核心链路已端到端实测：嗅探 → 队列 → 下载 → 分片合并 → 转码成 mp4 / mp3
- Android 在 USB 真机上跑，A2 已通过；MediaStore 导出与原生 FFmpegKit 转码已实现
  （2026-11-12），转换成功后自动写进系统媒体库（否则 `Android/data` 用户进不去、
  会以为文件没生成），待 B 组真机用例验证
- 转换任务有独立页面（入口在下载页 AppBar）并落盘 `transcode_jobs.json`：
  重启后 pending 继续跑、running 标成中断
- 下载记录也落盘（`download_tasks.json`，2026-11-12）：重启后历史还在，
  没下完的标「已中断，可重试」且不自动重跑（地址会过期）
- 鸿蒙嗅探代码已写但未真机验证；原生导出与转码仍未接入，入口保持隐藏
- `ohos/` 平台目录尚未生成（需 Flutter-OH SDK 与 DevEco Studio）

## 能力边界

DRM（Widevine / FairPlay）、签名 + MSE 拼流站点（YouTube 等）、`blob:` 资源不支持；
DASH 不做 MPD 分片重组，只处理嗅探到的完整 `.m4s` 分片（含音视频自动配对合并）。
合规说明见 `docs/tech-design.md` 第 9 节。
