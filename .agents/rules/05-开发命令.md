# 开发命令

```bash
flutter pub get
dart format .
flutter analyze          # 必须零 issue
flutter test
flutter run -d windows
flutter run -d <android>
```

## 端到端验证

两套真实链路验证默认跳过，需显式开启：

```bash
SNIFF_E2E=1 flutter test test/download_real_e2e_test.dart  # 单文件 / HLS 合并 / AES-128 解密，12 项
SNIFF_E2E=1 SNIFF_VERIFY=hls flutter test test/download_real_e2e_test.dart   # 只跑 HLS 那组
RUN_E2E=1 flutter test test/download_queue_e2e_test.dart   # 需要网络
RUN_E2E=1 flutter test test/transcode_e2e_test.dart        # 需要网络 + 本机 ffmpeg
```

`tools/verify_download.dart` 用本地 HTTP 服务提供 playlist、真实 CDN 分片；AES 那组刻意
不写 `IV`，逼着下载器按 RFC 8216 从媒体序列号推导（写错不报错，只产出乱码）。
**`dart run tools/verify_download.dart` 跑不起来**：下载链路依赖 `flutter/foundation`，
`dart run` 没有 `dart:ui`，连编译都过不去。入口统一走上面那个 test。
改动下载 / HLS / 转码逻辑后，至少跑一遍它和 `flutter analyze`。

## 本机环境前提

- **代理**：`flutter test` / `flutter run` 可能因 flutter_tester 的 localhost WebSocket
  被代理拦截而报 `Invalid WebSocket upgrade request`。用
  `NO_PROXY="localhost,127.0.0.1" flutter test`，或临时清空
  `http_proxy` / `https_proxy` / `HTTP_PROXY` / `HTTPS_PROXY`。
- **Windows 构建**：需要 WebView2 Runtime 与 `nuget.exe`（本机在
  `~/.devtools/nuget.exe`，构建时前置到 PATH），缺 NuGet 会报 `NUGET-NOTFOUND`。
- **FFmpeg**：桌面转码需要本机 `ffmpeg` + `ffprobe`，查找顺序见 `03-版本策略.md`；
  安装脚本 `bash ~/.devtools/get-ffmpeg.sh`。缺 ffprobe 仍能转换，只是不显示百分比。
  Android 不需要本机 ffmpeg，AAR 由 Gradle 从 Maven Central 拉取（首次构建约 8 分钟）。
- **Android 构建**：`flutter build apk --debug`，不需要再带 `--target-platform`：
  32 位 ABI 已由 `packaging.jniLibs.excludes` 剔除，32 位真机会在安装阶段报
  `NO_MATCHING_ABIS`。确认 so 是否打进包用 `unzip -l <apk> | grep libffmpegkit`。
- **鸿蒙构建**：需另装 Flutter-OH SDK 与 DevEco Studio，`ohos/` 目录尚未生成。

下载日志与原生崩溃排查方式见 `README.md`「排查问题」一节。
