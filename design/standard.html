09 布局间距与悬浮规范 Spacing / Glass

间距刻度（基础单位 4px）

--sp-1 = 4px 图标-文字 / 紧凑元素间
--sp-2 = 8px chips 间 / 组内行间
--sp-3 = 12px 卡片间 / 网格间距
--sp-4 = 16px 页面左右内边距（基准）
--sp-5 = 20px 分组与页面的额外强调
--sp-6 = 24px 卡片内边距（大）
--sp-7 = 32px 区块之间
--sp-8 = 40px 页面级留白 / 空态左右

页面结构尺寸

外阴影使用场景

shadow-1 静置卡片 / 分组
shadow-2 悬浮卡片 / 吸顶 / 滑块
shadow-3 下拉菜单 / 对话框
shadow-drawer 底部抽屉（上抛）
shadow-brand 渐变按钮 / FAB 光晕
shadow-glass 毛玻璃悬浮控件

毛玻璃（Glassmorphism）：悬浮于内容之上的控件（嗅探 FAB、悬浮工具球）使用 --glass-bg + backdrop-filter: --glass-blur + 1px --glass-border 描边 + --shadow-glass。毛玻璃控件上禁止再用渐变填充；内部图标可用渐变或品牌色。普通页面内控件（按钮、输入框）不用毛玻璃。
